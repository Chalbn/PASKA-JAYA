# ADR-007 Kategori otomatis

**Status**: Accepted · 2026-11-14

## Konteks
Filter kategori Master Item harus ikut bertambah saat produk baru.

## Keputusan
Tabel categories; form item memakai combobox (pilih atau ketik baru → dibuat otomatis); dropdown filter dari categories yang punya item.

## Konsekuensi
Hindari kategori kosong di filter.
