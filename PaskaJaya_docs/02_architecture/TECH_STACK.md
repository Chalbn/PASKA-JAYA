# Tech Stack
| Lapisan | Pilihan |
|---|---|
| Backend | Laravel 11+ (PHP 8.3) |
| Frontend | React 18 + TypeScript via **Inertia.js** |
| Styling | Tailwind CSS, font Plus Jakarta Sans |
| Chart | Recharts (bar/stacked bar) |
| Ikon | lucide-react |
| DB | MySQL 8 (SQLite untuk dev/test) |
| Auth | Session (Laravel) + role middleware |
| Export | maatwebsite/excel (xlsx, CSV), barryvdh/laravel-dompdf (PDF) |
| Storage | disk `public` (foto barang, avatar, bukti antar) |
| Test | Pest |
| Lint | Pint, ESLint, Prettier |
| Scheduler | `drawer:reset` 00:00, `backup:run` 02:00 |
