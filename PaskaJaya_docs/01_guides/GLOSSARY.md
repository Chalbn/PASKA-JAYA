# Glossary
| Istilah | Arti |
|---|---|
| Bon | Nota utang/pesanan pelanggan, bisa dibayar belakangan & diantar |
| Barang Keluar | Penjualan langsung (cash/transfer), lunas saat itu |
| Master Item | Katalog barang + stok + harga |
| Stok menipis | `stock <= min_stock` (ditampilkan "Kritis: n" bila ≤ batas) |
| Saldo Laci | Total uang masuk hari ini (cash + transfer), reset 00:00 |
| Lewat tempo | Bon belum lunas dengan `due_date` < hari ini |
| Sisa | `total - paid_amount` |
| Status Pembayaran | Belum Lunas / Lunas |
| Status Pengantaran | Belum Dikirim → Dikirim ke Karyawan → Sedang Disiapkan → Siap Berangkat/Sedang Diantar → Selesai |
| Bahan Harian | Pengeluaran operasional harian (bensin, tali, plastik, dll.) |
| Kehadiran | Catatan karyawan hadir + pekerjaan yang dilakukan |
| Tim | Profil tim pembuat web (halaman Admin) |
