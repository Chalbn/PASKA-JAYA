# Git Workflow
- Branch: `main` (stabil), `develop`, fitur `feat/<role>-<fitur>`, perbaikan `fix/...`.
- Commit: Conventional Commits — `feat(kasir): barang keluar`, `fix(bon): hitung sisa`, `docs: ...`.
- PR kecil, 1 fitur. Wajib: lint + test hijau.
- Jangan commit `.env`, `storage/app/public/*`, `node_modules`, `vendor`.
